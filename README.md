# iStoreOS 双宽带 mwan3 流量调度配置指南（方案 B）

基于 **EasePi-R1 Pro（iStoreOS / OpenWrt）** 的双宽带落地配置手册：电信 + 移动两条宽带，光猫各自拨号、路由器 DHCP 取址，下挂普通非网管交换机，单网段，由 **mwan3** 决定出口，支持**主备切换**与**负载均衡**两种模式。

## 方案要点

- 单网段 `192.168.100.0/24`（示例地址，按实际网络修改），普通傻瓜交换机零配置。
- 两个 WAN：电信 `eth0`、移动 `eth1`，分别从各自光猫 DHCP 获取地址。
- mwan3 成员 / 策略 / 规则配置；主备按跃点分主次，均衡按权重分连接。
- 含默认网关与成员路由、探测地址选择、DNS hosts 格式、故障速查、IPv6 说明，以及均衡 / 主备互切步骤与验收方法。

## 两种调度模式

| 模式 | 成员跃点 / 权重 | 表现 |
|---|---|---|
| 主备 · 移动优先（推荐默认） | 移动 1/1，电信 2/1 | 平时全走移动，移动掉线切电信，恢复后切回 |
| 负载均衡 1:1 | 两者都 1/1 | 两条线同时承载，按连接分配 |
| 负载均衡 2:1 | 按权重调整 | 多连接 / 多线程下载时总带宽近似叠加 |

> mwan3 按连接分配，不按字节拆包：单个下载任务、单线程测速只走一条线；多设备并发、多线程下载才能体现两条线叠加。

## 适用环境

- 路由器：EasePi-R1 Pro（RK3568，预装 iStoreOS），其他 OpenWrt / iStoreOS 设备思路通用。
- 光猫：两台均为路由模式（自己拨号），路由器作 DHCP 客户端，不做 PPPoE 拨号。
- 交换机：普通非网管交换机即可，不需要网管交换机做 VLAN。

## 说明与免责
